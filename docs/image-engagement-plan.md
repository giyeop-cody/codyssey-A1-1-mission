# 이미지 피처의 활용 방향 — 2026-10-12

## 원문 요구와 현재 구현

원문은 이미지별 평균·표준편차를 NumPy 배열 연산으로, 상품명 단어 수 또는 문자열 길이를 텍스트 파생 변수로 요구한다. 현재 `img_mean`, `img_std`, `name_word_count`, `name_length`를 생성한다. 이미지 값은 RGB를 255로 나눈 0~1 기준이다. RGB 전체 평균은 사람이 느끼는 휘도와 동일하지 않다.

이미지–가격 상관은 변수 두 쌍 이상의 상관분석을 위한 보조 EDA 선택이다. 가격과의 상관으로 클릭률·구매 전환의 효과나 이미지 실험의 필요성을 판정하지 않는다. 합성 이미지에 가격 신호가 포함되므로 실제 시장 관계의 증거도 아니다.

## 선행 연구와 가설

[Chae, Nakazawa, Stenger, ICIP 2018](https://bjornstenger.github.io/papers/chae_icip2018.pdf)는 카테고리별 밝기·대비·선명도·주목 영역 특성을 사용했다. 밝기·대비·선명도를 함께 보정하고 일주일간 100,720회 노출·1,119회 클릭을 측정한 A/B 테스트에서 평균 CTR 상대 증가 15.7%를 보고했다. 음식·패션에서 유의한 증가가 있었으나 모든 카테고리에서 개선된 것은 아니다. 밝기 단독의 단조 증가 효과나 구매 전환 개선을 입증한 결과가 아니다.

가설: 동일 상품·노출 조건에서 상품 디테일을 잃지 않도록 밝기와 대비를 개선하면 CTR이 개선되는가? 구매 전환도 개선되는가? 과노출 조건에서는 효과가 약해지거나 반전되는가?

## 추가 피처 계획 — 아직 구현하지 않음

- 필수 RGB 평균·표준편차를 유지하고 별도로 휘도 평균·표준편차를 계산한다. 휘도 계산 방식과 색 공간을 기록한다.
- 배경과 상품 영역의 밝기를 구분한다. 흰 배경·흰 상품을 과노출이라고 자동 판정하지 않는다.
- 높은 휘도 또는 채널 클리핑 비율은 과노출 후보 지표로 사용한다. 마스크·임계값을 명시하고 실제 디테일 손실을 표본 검수한다.
- 선명도·상품 점유율은 추가 통제 후보다. 평균·표준편차만으로 상품 식별 가능성을 충분히 설명할 수 없다.

## 필요한 로그와 지표

이미지 자산 표에는 `product_id`, `image_version`, 피처와 보정 조건을 기록한다. 이벤트 로그에는 실험 배정, 시간, 세션 식별자, 노출 위치, 노출·클릭·구매 이벤트를 연결한다. 가격·할인·카테고리·재고·기기·유입경로도 비교 조건에 포함한다. 주문 중복과 구매 귀속 기간을 사전에 정의한다.

- CTR = 이미지에 귀속된 클릭 수 / 이미지 노출 수.
- 구매 전환율 = 구매한 세션 수 / 대상 세션 수. 대상 세션과 구매 귀속 기간을 고정한다.
- 노출당 구매율과 노출당 매출·이익을 보조 지표로 둔다. CTR 상승만으로 구매 개선을 주장하지 않는다.

상품이나 카테고리 간 단순 상관은 탐색용이다. 같은 상품의 원본/보정 이미지를 같은 위치에서 무작위 배정하고, 반복 방문자의 배정은 일관되게 유지한다. 밝기 단독 효과를 보고 싶다면 다른 보정은 고정하거나 요인 실험으로 분리한다.

카테고리별·전체 효과의 절대 차이와 상대 변화, 신뢰구간을 보고한다. 반복 관측의 상관과 다중 비교를 고려한다. 기준 CTR, 최소 검출 효과, 유의수준, 검정력으로 표본수를 사전 산정한다. 상품당 7,000건 같은 고정 수치를 보편적 조건으로 사용하지 않는다.

## 확인 범위

현재 합성 데이터에는 이미지 노출·클릭·세션 기록이 없다. 거래 기록을 노출·클릭의 대체값으로 사용하거나 가짜 CTR을 생성하지 않는다. 필수 피처 추출과 보조 EDA는 실행된 결과이고, 본 문서의 참여·전환 분석은 추가 데이터가 필요한 실험 계획이다. 원문 충족을 위해 이 확장 실험을 반드시 완료할 필요는 없다.
