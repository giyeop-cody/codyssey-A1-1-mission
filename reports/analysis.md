- 실제 상품 설명 결측은 3건이며 `unknown` 처리 후 0건이다. 실제 가격 결측은 0건이다.

- 전체 중앙값 MAE: **0.0189615127** / 카테고리별 중앙값 MAE: **0.0179413479** (정규화 가격 단위).
- 이 수치는 합성 정답지가 아니라 실제 관측값 홀드아웃이다. 메인 분석의 가격은 가리지 않았다.

## 실제 이미지 피처와 NumPy 축 연산

- `(N,32,32,3) uint8` 실제 이미지에서 RGB/255 평균·표준편차·채도 범위를 계산했다. 이미지를 가격에 맞춰 밝히지 않았다.
- 전체 벡터화 0.053013s / 이미지별 NumPy 루프 0.018733s. 1장당 순수 Python 0.00037069255333335607s, 벡터화 2.3099346405228758e-05s (순수 Python 표본 150장).
- 시간은 하드웨어·배열 크기에 따라 바뀌므로 절대 배율보다 세 경로의 측정 조건을 함께 본다.

## RFM 세분화

기준일은 최종 거래 다음 날이다. R만 역전하고, 짧은 기간의 정수 빈도 동률은 평균순위로 같은 점수를 부여했다. F는 주문/바구니가 아니라 **고유 거래행 수**다.

| 세그먼트 | 고객 수 | 매출지표 점유 | 평균 Recency(일) | 평균 거래행 수 |
|---|---:|---:|---:|---:|
| 대체고객 | 277 | 7.8% | 11.02 | 1.36 |
| 성장고객 | 208 | 9.5% | 7.66 | 2.01 |
| 우수고객 | 279 | 26.4% | 7.58 | 3.85 |
| VIP | 234 | 56.3% | 4.62 | 8.65 |

- VIP 평균 Recency **4.62일**, 비VIP **8.85일**, 전체 중앙값 8.00일; 방향 게이트=True.
- R을 역전하지 않은 실패 모드의 VIP 평균 Recency는 **10.09일**이다.

## 사업 제안 (근거 → 실행 → 검증)

1. **단기 VIP를 후보로 하되 실제 발송 전 긴 이력으로 재계산한다.**
   - 근거: VIP 234명이 정규화 매출지표의 56.3%를 차지한다.
   - 실행: **대상 세그먼트는 VIP 234명**이다. 최소 6~12개월 이력으로 RFM을 다시 계산한 뒤 재구매 캠페인 대상을 시뮬레이션한다. **기대 효과는 재구매율·유지율 개선 여부를 확인하는 것**이며 효과를 미리 단정하지 않는다.
   - 검증: 사전 정한 대조군과 이후 재구매율·유지율·1인당 매출을 비교하고, 차이가 없으면 VIP 캠페인 가설을 반증된 것으로 본다. 15일 단면으로 캠페인 효과를 주장하지 않는다.
2. **상품 설명 누락과 가격 누락을 분리한 품질 게이트를 둔다.**
   - 근거: 실제 설명 결측 3건, 가격 홀드아웃 그룹 대치 MAE 0.0179413479.
   - 실행: **대상 세그먼트는 VIP·우수·성장·대체고객 전체의 상품 탐색에 필요한 설명·가격 누락 레코드**다. 텍스트는 `unknown`으로 표시하고 가격은 카테고리별 중앙값과 소그룹 전체 중앙값 fallback을 적용한다. **기대 효과는 결측으로 인한 분석 제외와 대치 오차 감소**다.
   - 검증: 추가로 확보한 실제 가격을 같은 해시 규칙으로 홀드아웃해 MAE를 재측정한다. 그룹 대치가 전체 중앙값보다 악화되면 현재 선택이 반증되므로 전체 중앙값으로 되돌린다.
3. **이미지 피처는 가격 결론이 아니라 참여 실험의 입력으로 제한한다.**
   - 근거: 실제 이미지–가격 Pearson 원본 r=-0.1576; 노출·클릭·세션은 0개다.
   - 실행: **대상 세그먼트는 VIP·우수고객**이며, 이들에게 동일 상품의 원본/보정 이미지를 가격과 노출위치가 같은 조건으로 무작위 배정하는 별도 실험을 설계한다. **기대 효과는 CTR·구매 전환 개선 여부를 검증하는 것**이다.
   - 검증: 추가로 노출·클릭·세션·구매와 무작위 배정 로그를 수집해 CTR과 구매 전환을 나누어 비교한다. 대조 차이가 없으면 이미지 가설은 반증되며, 현재 상관을 실험 효과로 인용하지 않는다.

## 한계

- GitHub 미러의 거래는 원본 마지막 15일 부분집합이다. 장기 충성도, 계절성, 진짜 VIP를 식별하는 분석이 아니다.
- 고객 표본 내 가격 중앙값이며 일부 상품은 거래 수가 적다. `transaction_count`를 함께 보고 전체 H&M 가격으로 일반화하지 않는다.
- 이미지는 미러가 256×256으로 축소한 실제 상품 사진이며 이 코드가 32×32 RGB로 다시 축소했다. 원본 해상도의 질감·선명도 평가는 불가능하다.
- 원본 규칙은 비상업·학술/교육 용도다. 원본 CSV, 고객별 RFM, 원본/파생 이미지 배열은 Git에 올리지 않는다.
